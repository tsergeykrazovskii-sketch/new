# Сайт бренда «Жар-соус»

Одностраничный сайт бренда острых соусов: линейка с фильтром, окно соуса (состав, КБЖУ, хранение), шкала остроты, подбор соуса к блюду, отзывы, подарок, ресторанам, где купить (Ozon и Wildberries).

- `src/content.json` — тексты, соусы (короткие названия, вкус, к чему, острота), отзывы, вопросы; `_sources` и `_todo`.
- `src/ozon-raw.json` — данные карточек Ozon (28.10.2026): ссылки, рейтинг, число отзывов, состав, КБЖУ, хранение, фото.
- `img/` — фото атмосферы (Higgsfield, без упаковки), `img/products/<артикул>.webp` — фото упаковок с Ozon (`node zhar/fetch-images.mjs`, нужен доступ к ozone.ru). Пока их нет — на сайте ссылки на фото Ozon.
- `node zhar/build.mjs [--base-url https://домен/]` → `zhar/dist/` (index.html, img, fonts, robots.txt, sitemap.xml с адресом). Папку `dist` целиком — на хостинг.
