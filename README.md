# Слот

Универсальный шаблон сайта для локального сервисного бизнеса с онлайн-записью. Один движок, разные ниши: дизайн, тексты, услуги и сценарий записи задаются конфигом ниши.

Продаются как отдельные продукты на общем движке:

- **Слот Барбер** — стили «Классика» (по умолчанию), «Американ», «Табак»;
- **Слот Авто** — стили «Цех» (по умолчанию), «Диагностика», «Спорт».

Стиль — это набор из шрифтов, цветов, скруглений, текстуры и характера анимации. Клиент выбирает стиль, дальше меняются только тексты, цены и фото. «Слот» — рабочее название.

## Что внутри

- Первый экран с живым виджетом: у барбершопа — свободные окна мастеров на сегодня, у автосервиса — калькулятор стоимости по марке авто и ближайшее окно.
- Онлайн-запись в 3–4 шага: услуга → мастер → дата и время → контакты, с согласием на обработку ПД по 152-ФЗ.
- Статус «Открыто до 22:00» по часовому поясу точки.
- Услуги с ценами по вкладкам, мастера, акции, работы, отзывы с Яндекс Карт и 2ГИС, частые вопросы, контакты и часы работы.
- Мобильная панель «Позвонить / Написать / Записаться», кнопки Telegram, MAX, ВКонтакте.
- Разметка Schema.org (`BarberShop`, `AutoRepair`) для поиска.
- Анимация первого экрана, подложка вкладок, «докручивающаяся» цена в калькуляторе, переходы между шагами записи. Учтена настройка «уменьшить движение».
- Чистый HTML/CSS/JS без зависимостей: сайт собирается в один файл и размещается на любом хостинге в РФ.

## Структура

```
index.html            демо для разработки, переключает ниши
assets/css/slot.css   стили, цвета берутся из темы ниши
assets/js/render.js   конфиг → HTML (работает в браузере и в Node)
assets/js/app.js      поведение: тема, статус, окна, калькулятор, запись
niches/*.js           конфиги ниш: тема, контакты, услуги, мастера, секции
scripts/build.mjs     сборка в dist/
docs/                 анализ рынка
```

## Как посмотреть

Откройте `index.html` в браузере или соберите проект:

```
node scripts/build.mjs
```

В `dist/` появятся `barber.html` и `auto.html` (готовый сайт одним файлом в стиле по умолчанию, разметка отрендерена заранее для SEO) и `demo-barber.html`, `demo-auto.html` (демо с переключателем стилей). Для разработки: `index.html` — барбершоп, `index.html#auto` — автосервис.

## Как добавить нишу или клиента

Скопируйте `niches/barber.js`, поменяйте `id`, стили (`styles`: токены, шрифты, `motion`: `elegant` / `mechanical` / `bold`), контакты, услуги и порядок секций в `sections`, затем запустите сборку. Доступные секции: `hero`, `perks`, `services`, `staff`, `steps`, `offers`, `gallery`, `reviews`, `faq`, `contacts`.

Все имена, цены, отзывы и реквизиты в демо-конфигах вымышленные.
