# TOPIN — логотип и брендбук в векторе

Восстановлено по брендбуку в низком качестве. Все SVG в кривых: шрифты ставить не нужно, файлы открываются в Figma, Illustrator, Inkscape и в браузере.

## Файлы

| Папка | Что внутри |
|---|---|
| `topin-brandbook.svg` | брендбук целиком, лист 1536×1024 (PNG 3072×2048 — в `png/`) |
| `logo/topin-primary-*.svg` | основная версия: TOPIN + DIGITAL VISIBILITY AGENCY |
| `logo/topin-horizontal-*.svg` | горизонтальная: TOPIN │ слоган в три строки |
| `logo/topin-compact-*.svg` | компактная: только TOPIN |
| `icon/topin-icon-yellow / black / light.svg` | иконка приложения 512×512, скругление 104 |
| `icon/topin-mark-color(-inverse).svg` | знак «N» без подложки |
| `icon/favicon.svg`, `icon/favicon.ico` | иконка сайта (ico — 16, 32, 48 px) |
| `png/` | всё то же в PNG с прозрачным фоном: логотипы 3000 px по ширине, иконки 512 и 1024, favicon 16–512 (180 — для iPhone, 192/512 — для Android) |

Варианты цвета у каждого логотипа:

- `color` — чёрный + жёлтый, для светлого фона (основная);
- `color-inverse` — белый + жёлтый, для тёмного фона;
- `mono-black`, `mono-white` — один цвет; жёлтый клин в «N» вырезан и становится цветом фона, как на жёлтой иконке.

## Цвета

| | HEX | RGB |
|---|---|---|
| Жёлтый (акцент) | `#F6E300` | 246, 227, 0 |
| Чёрный (основной) | `#0B0B0B` | 11, 11, 11 |
| Серый (вторичный) | `#6B6B6B` | 107, 107, 107 |
| Светлый (фон) | `#F5F5F5` | 245, 245, 245 |

## Шрифты

- TOPIN — буквы T, O, P, I из Montserrat ExtraBold (на 6 % шире, по замерам оригинала), «N» построена геометрически: левая ножка, диагональ и правая ножка, в которой жёлтый клин.
- Слоган — Montserrat Medium, разрядка по ширине знака.
- Тексты брендбука — Manrope, как указано в разделе «Типографика».

Оба шрифта бесплатные (SIL Open Font License), с кириллицей.

## Правила

- Охранное поле: x = высота буквы T, со всех сторон.
- Минимальный размер на экране: 120 px по ширине знака TOPIN.
- В файлах нет полей вокруг логотипа: при вёрстке оставляйте охранное поле.

## Пересобрать

```
python3 brand/topin/src/build.py      # логотипы и иконки (нужен fonttools: pip install fonttools brotli)
python3 brand/topin/src/brandbook.py  # лист брендбука
node brand/topin/src/png.mjs          # PNG (нужен Playwright)
```

Буквы берутся из шрифтов проекта (`assets/fonts/files`), геометрия «N» и размеры заданы в `src/build.py`.
