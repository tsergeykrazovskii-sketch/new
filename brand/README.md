# Логотип «В ТОП — начни с вершин» (top-in.ru)

Перерисован в вектор с PNG 153×44. Пропорции те же (153 : 44), буквы переведены в кривые: шрифты на сайте не нужны.

| Файл | Для чего |
|---|---|
| `logo-v-top.svg` | основной, для светлого фона (лучше всего для сайта) |
| `logo-v-top-dark.svg` | для тёмного фона: «ТОП» и линии белые |
| `logo-v-top.png`, `logo-v-top@2x.png` | 1530×440 и 3060×880, прозрачный фон |
| `logo-v-top-dark.png` | 1530×440, для тёмного фона |
| `icon-v-top.svg`, `icon-v-top-512.png` | только значок с горой (аватарка, иконка сайта) |

На сайте: `<img src="logo-v-top.svg" alt="В ТОП" height="44">`, ширина подстроится сама.

Цвета: «В» — `#DA9E6B`, «ТОП» и линии — `#000000`, подпись — `#4A4849`, рамка — `#8C8A8B`, грань горы — градиент `#EC8A33` → `#F3AE70`.

Шрифты (лицензия SIL OFL, можно в логотипе): «В ТОП» — Didact Gothic, подпись — Montserrat.
