# Шаблон сайта бренда для маркетплейсов

Одностраничный сайт бренда, который продаёт на Ozon и Wildberries: свой сайт ведёт покупателя в карточки маркетплейсов и собирает оптовиков. Не на движке «Слота» — своя сборка, без админки.

Сейчас заполнен на примере бренда острых соусов «Жар-соус» (данные с Ozon, 28.10.2026). Клиент отказался от сайта 29.10.2026, демо на demo.top-in.ru снято. Для нового бренда заменяются данные, фото и цвета, блоки остаются.

Блоки: первый экран с хитами и кнопками Ozon / WB, бегущая строка, линейка с фильтром и окном товара (состав, КБЖУ, хранение), шкала «насколько остро» (у другого товара — своя шкала или убрать), подбор к блюду, «чем отличается», отзывы с маркетплейсов, «в подарок», «оптовикам» (магазины, HoReCa, корпоративные подарки, проверенный спрос, характеристики), где купить, вопросы, подвал. Меню-бургер на телефоне, полоса прокрутки, нижняя панель Ozon / WB.

- `src/content.json` — тексты, товары (короткие названия, вкус, к чему, острота), отзывы, вопросы; `_sources` и `_todo`.
- `src/ozon-raw.json` — данные карточек Ozon: ссылки, рейтинг, число отзывов, состав, КБЖУ, хранение, фото. Как их собрать: API страницы Ozon `https://www.ozon.ru/api/entrypoint-api.bx/page/json/v2?url=<адрес страницы бренда или товара>` (виджеты `tileGrid…`, `webProductHeading`, `webDescription`, `webCharacteristics`, отзывы — `<товар>/reviews/`).
- `img/` — фото атмосферы (Higgsfield, без упаковки), `img/products/<артикул>.webp` — фото товаров с Ozon (`node marketplace/fetch-images.mjs`, нужен доступ к ozone.ru). Без них на сайте ссылки на фото Ozon, а Ozon не показывает их на чужих сайтах — перед сдачей фото обязательно скачать.
- Шрифты: заголовки — Manrope 800, рукописные акценты (`<span class="hand">`) — Caveat; берутся из `assets/fonts`.
- `node marketplace/build.mjs [--base-url https://домен/] [--demo]` → `marketplace/dist/` (index.html, img, fonts, robots.txt, sitemap.xml с адресом). Папку `dist` целиком — на хостинг. `--demo` — закрыть от поисковиков.
