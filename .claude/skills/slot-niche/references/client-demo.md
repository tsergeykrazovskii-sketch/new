# Демо для реального бизнеса

Цель — чтобы владелец открыл ссылку и узнал свой бизнес: его название, адрес, услуги, цены, отзывы и фото. Именно это и продаёт, поэтому данные должны быть настоящими.

## 1. Собрать данные

- **Откуда.** Яндекс Карты, 2ГИС, сайт или Taplink, ВКонтакте, YCLIENTS / DIKIDI (там прайс и мастера), агрегаторы отзывов.
- **Если сайты не открываются.** Российские сайты из этой среды не открываются, работает поиск. Пользователь может прислать ссылки, скриншоты или текст страницы (выделить всё и скопировать), а может открыть доступ к домену в настройках сети.
- **Что собрать:** название и написание, адрес и метро, телефон, часы, прайс с длительностью, мастера, рейтинг и число отзывов по площадкам, 4–8 отзывов дословно с именем и датой, фото, способ записи сейчас, реквизиты.
- **Источник у каждого факта.** Пиши в `_sources` откуда и когда взято. Чего нет — в `_todo`.

**Не выдумывать.** Отзывы, имена мастеров, цены и регалии берём только из источников. Если цен нет, раздел прайса честно показывает «по запросу» или «уточните цены» и попадает в `_todo`. Исключение, принятое пользователем, — у автосервисов без прайса: временные цены «от 1 000 ₽» с пометкой «Цены для примера».

## 2. Файл клиента `clients/<slug>.json`

Структура — как у конфига ниши, но без стилей ниши и без её демо-контента:

```json
{
  "slug": "alistyle",
  "niche": "barber",
  "style": "american",
  "timezone": "Europe/Moscow",
  "demoLabel": "Демо сайта для барбершопа «Alistyle» · данные из открытых источников · не официальный сайт",
  "_sources": ["yandex.ru/maps/org/… — адрес, часы, 4,9 и 312 отзывов (30.10.2026)"],
  "_todo": ["Прайс — в картах цен нет", "Реквизиты для подвала и политики ПД"],
  "brand": { … }, "contacts": { … }, "hours": [ … ], "nav": [ … ], "hero": { … },
  "services": [ … ], "staff": [ … ], "booking": { … }, "schedule": { … }, "sections": [ … ], "legal": { … }
}
```

- `demoLabel` — плашка «демо, не официальный сайт» сверху. Обязательна, пока сайт не куплен.
- `style` — один из стилей ниши. Для фирменного стиля клиента добавь в `styles` свой стиль (см. `clients/tor.json`).
- Если бизнес уже записывает через YCLIENTS или DIKIDI, укажи `"schedule": { "mode": "external", "url": "<их страница записи>" }`. Владелец увидит, что сайт ничего не ломает в его процессах.
- Карта: `contacts.yandexMaps` в виде `yandex.ru/maps/org/<имя>/<id>/` даёт живой виджет организации.

## 3. Фото

1. **Сначала настоящие фото бизнеса:** с карточек, сайта и соцсетей. Обработка: `python3 scripts/images.py <исходники> clients/<slug>/img`, пути в данных — `img/<файл>.webp`.
2. **Нейросеть — только атмосфера:** руки, инструменты, детали, продукт крупно. Зал, команду, работы и упаковку показываем только настоящими: иначе демо вводит в заблуждение, а владелец это сразу видит.
3. **Портреты нейросетью** — только у вымышленных мастеров шаблонов ниш. У клиента мастер без фото остаётся без фото: в админке это просьба загрузить своё.

## 4. Собрать и проверить

```bash
node scripts/build.mjs
SMOKE_ONLY=<slug> PLAYWRIGHT=/opt/node22/lib/node_modules/playwright/index.mjs CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome node scripts/smoke.mjs
PLAYWRIGHT=/opt/node22/lib/node_modules/playwright/index.mjs CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome node scripts/share.mjs <slug>
node scripts/build.mjs
```

Демо будет по адресу `https://demo.top-in.ru/<slug>/`, админка — `/<slug>/admin/`, а также в закрытой витрине. Превью ссылки (`share.mjs`) важно: владелец часто видит сначала картинку в мессенджере.

## 5. Сдача после продажи

Комплект для хостинга клиента — `release/<slug>/` (собирается той же сборкой): сайт, `data.json`, админка с `api.php`, шрифты, коды первого входа. Как загрузить, задать пароль, включить HTTPS и уведомления — `docs/handover.md`. Перед первым запуском на рабочем домене пройдитесь с пользователем по безопасности: сроки хранения заявок, HTTPS, лимиты, бэкапы.
