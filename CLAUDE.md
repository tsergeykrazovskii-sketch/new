# Слот — памятка для работы над проектом

Продукт пользователя: персональные демо-сайты для локального бизнеса в России (барбершопы, автосервисы). Модель продаж: показать владельцу демо на его реальных данных («вау»), продать за 10–15 тыс. ₽ и отдать всё (сайт на его хостинге + админка). Не SaaS, без подписки и без наших серверов.

Всё общение и весь текст на сайтах — на русском. Ветка разработки: `claude/admiring-shannon-unr8lw`.

## Как устроено

- `niches/barber.js`, `niches/auto.js` — шаблоны ниш: стили (токены, шрифты, `motion`), секции по умолчанию, настройки записи. Их демо-контент («Ремесло», «Поршень») вымышленный.
- `clients/<slug>.json` — данные реального клиента. `Slot.compose` берёт от ниши только оформление и поведение, весь контент — только из файла клиента. Демо-данные ниши к клиенту попадать не должны.
- `assets/js/render.js` — конфиг → HTML, `assets/js/page.js` — сборка страницы, `assets/js/app.js` — поведение (запись, окна, калькулятор, просмотр фото).
- Карта в контактах: живой виджет Яндекса по ссылке на организацию (`contacts.yandexMaps` вида `yandex.ru/maps/org/<имя>/<id>/`) или по коду из «Поделиться → Встроить карту» (`contacts.mapWidget`). У демо-ниш организации нет — карта по координатам (`contacts.coords`: [широта, долгота]).
- Тема «Своя»: `data.customTheme` (3 цвета, шрифты из `Slot.FONTS`, углы, отступы `--space`, анимация) → `Slot.customStyle` собирает полный стиль с проверкой контраста; в админке — вкладка «Оформление». Технические требования для клиентов: https://claude.ai/artifact/BriTpuszjYf7SZpLvc8vBo
- `admin/` — админка владельца: редактирует `data.json`, «Сохранить» пересобирает `index.html` в браузере, `api.php` сохраняет на хостинге клиента (PHP 8, без БД). Пароль задаётся только с кодом первого входа (`setup_code` в `admin/config.php`, сборка генерирует его в комплект). Лимиты входа и заявок — по IP в `admin/private/limits.php`. Письма — через SMTP из `config.php` или `mail()`. Как сдавать — `docs/handover.md`.
- `node scripts/build.mjs` → `dist/` (Vercel: шаблоны `/barber/`, `/auto/` и клиенты `/<slug>/`, у каждого демо-админка `…/admin/`; правки в ней хранятся в браузере и видны на странице; `vercel.json` — адреса со слешем на конце) и `release/<slug>/` (комплект для хостинга клиента). GitHub Pages: `.github/workflows/pages.yml` собирает с `SITE_BASE=/<репозиторий>` (сайт в подпапке) после пуша в основную ветку.
- Фото: `python3 scripts/images.py <исходники> clients/<slug>/img` или `assets/img/<ниша>`. В конфиге ниши путь от корня `/assets/img/<ниша>/<файл>.webp` (сборка копирует папку в `dist/assets/img/`), у клиента — `img/<файл>.webp`. Список кадров — `docs/shotlist.md`.

## Правила

- Данные клиента — только проверенные, с источником в `_sources`; чего нет — в `_todo`, не выдумывать (особенно отзывы, имена, цены).
- Нейросетевые фото для реальных клиентов — только атмосфера (руки, инструменты, детали); зал и команду показывать на их настоящих фото. Портреты нейросетью — только для вымышленных мастеров ниш.
- После правок: `node scripts/build.mjs`, проверка в Playwright (`/opt/pw-browsers/chromium-1194/chrome-linux/chrome`) на 390 и 1440 px — без ошибок в консоли и без горизонтальной прокрутки, запись проходит до «Вы записаны».

## Ограничения среды

Сеть окружения не пускает на российские сайты (Яндекс Карты, 2ГИС, YCLIENTS, сайты клиентов) и на фотобанки; работает поиск. Higgsfield генерирует только на платном тарифе; скачать результат можно, лишь если его домен добавлен в разрешённые (Network access).
